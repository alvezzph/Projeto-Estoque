# 📦 StockFlow

Sistema de Controle de Estoque Desenvolvido em Python.

---

# Objetivo

O objetivo do sistema é facilitar o gerenciamento de produtos em estoque, permitindo cadastrar, vizualisar, atualizar e remover produtosde forma prática.

---

## Funcionalidades

- Cadastro de Produtos
- Listagem de Produtos
- Atualização de estoque
- Remoção de Produtos
- Organização Modular do Sistema

---

# Tecnologias Ultilizadas

- Python
- Git
- GitHub
- Colab
- Canvas

# Como Executar

1. Clone o repositório:

 '''bash
 git clone https://github.com/alvezzph/Projeto-Estoque
 '''

2. Entre na pasta do projeto:

 '''bash
 cd estoque
 '''

3. Execute o programa:

 '''bash
 python main.py
 '''
